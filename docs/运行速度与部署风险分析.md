# 运行速度、内存与部署风险分析

## 当前状态

当前系统已经具备：

- YOLO 推理
- detection 后处理
- tracker
- realtime counting
- best crop
- debug video

但目前更接近：

```text
离线实验系统
```

还不是：

```text
长期实时部署系统
```

下面只保留影响最大的工程风险。

---

# 1. 视频写入是当前最大性能瓶颈

当前：

```python
writer.write(frame)
```

仍是同步执行。

已经观察到：

```text
不写视频：40+ FPS
写视频：20+ FPS
```

说明：

```text
真正拖慢系统的不是 YOLO
而是视频编码与 IO
```

真实部署时可能导致：

- 延迟累积
- 缓冲堆积
- 掉帧
- 实时统计滞后

---

# 2. Debug 功能与主流程耦合过重

当前：

```text
检测
计数
画框
视频保存
CSV
best crop
```

基本都在同一个主循环。

风险：

```text
debug 功能拖垮实时检测
```

真实部署中：

```text
检测与计数必须优先
debug video 只能是附属功能
```

---

# 3. track_records 长时间运行可能持续增长

当前：

```python
track_records = {}
```

会长期保存历史 track 信息。

其中还可能包含：

```python
best_crop.copy()
```

风险：

```text
运行 1~2 小时后内存持续上涨
```

短视频测试不明显，但长时间部署可能越来越慢。

---

# 4. best crop 当前是“内存保存”

目前：

```text
best crop 先存在内存
finalize 时再落盘
```

风险：

- 长时间占内存
- 异常退出可能丢图
- reconnect 频繁时长期不 finalize

真实部署更稳的方式应是：

```text
及时落盘
record 里只保存路径
```

---

# 5. 当前 FPS 统计不足以诊断问题

目前打印的是：

```text
累计平均 FPS
```

无法发现：

- 局部卡顿
- 短时掉速
- IO 阻塞
- track 暴涨

真实部署需要：

```text
window FPS
active_tracks
detections
track_records_size
GPU/CPU usage
```

否则后期很难定位性能问题。

---

# 6. 真实水体可能让 tracker 成本突然升高

真实环境中：

- 杂质更多
- detection 数量更多
- active tracks 更多

会导致：

```text
Hungarian matching
deduplicate
blob filter
```

成本明显增加。

因此：

```text
实验室 FPS
≠
真实环境 FPS
```

---

# 7. RTX Laptop 能跑，不代表边缘设备能跑

未来如果部署到：

- Jetson
- 边缘计算板
- 水下机器人

风险包括：

- CUDA 不兼容
- TensorRT 问题
- 显存不足
- CPU 太弱
- 编码器太慢
- 功耗与散热不足

很多系统：

```text
实验室电脑稳定
边缘设备直接崩
```

---

# 8. 长时间运行稳定性未知

当前大部分测试仍属于：

```text
短视频
```

但长期部署可能出现：

- 内存上涨
- writer 异常
- 相机断流
- 文件过大
- SSD 写满
- GPU OOM
- FPS 越跑越低

真实部署前必须做：

```text
1~3 小时压力测试
```

---

# 9. 实时系统最大的敌人是“延迟累积”

很多系统：

```text
平均 FPS 看起来够
```

但实际上：

```text
采集速度 > 处理速度
```

结果：

- 系统越来越“慢”
- 视频越来越滞后
- 实时计数失去意义

因此：

```text
实时系统不仅要看 FPS
更要看 latency
```

---

# 10. 当前最重要的工程方向

未来最重要的已经不是：

```text
再提高 3% detection accuracy
```

而是：

```text
让系统稳定连续运行数小时
```

当前最值得优先做：

1. finalized track 实时清理
2. window FPS 与资源监控
3. debug video 降级
4. 视频异步写入
5. best crop 及时落盘
6. 长时间压力测试
