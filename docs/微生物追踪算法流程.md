# 🧪 微生物检测与追踪算法流程

## 🔄 整体流程

```text
逐帧读取视频
→ YOLO 检测
→ detection 后处理
→ tracker 轨迹关联
→ 稳定轨迹筛选
→ 重复轨迹过滤
→ confirmed 计数
→ best crop 更新
→ 输出 CSV / 图片 / 视频
```

---

# 1️⃣ 视频读取

使用 OpenCV 逐帧读取显微视频：

```python
cap.read()
```

每帧进入后续推理流程。

---

# 2️⃣ YOLO 检测（Detection）

使用 YOLO 对当前帧进行目标检测。

输出：

- bbox
- conf
- cls_id

生成 Detection 对象：

```python
Detection(
    x1, y1, x2, y2,
    conf,
    cls_id
)
```

作用：

- 找出当前帧中的微生物候选目标

---

# 3️⃣ Detection 后处理（Postprocess）

## （1）Detection 去重

使用：

```python
deduplicate_detections()
```

依据：

- IoU
- 中心点距离

作用：

- 防止同一微生物生成多个框

---

## （2）亮斑过滤（Blob Filter）

使用：

```python
filter_blob_like_detections()
```

过滤：

- 高圆形度
- 低纹理变化
- 类似反光亮斑的区域

作用：

- 减少水下高亮误检

---

# 4️⃣ Tracker 轨迹关联（Tracking）

使用：

```python
MicrobeTracker
```

对 Detection 与历史 Track 进行匹配。

匹配依据：

- 中心距离
- IoU
- 尺寸变化
- 运动方向

结果：

- 匹配成功 → 更新旧 Track
- 匹配失败 → 新建 Track

作用：

- 判断是否属于同一个微生物

---

# 5️⃣ Lost Track Reconnect

当目标短暂丢失后：

```python
_try_reconnect_lost_track()
```

会尝试重新接回原 Track ID。

作用：

- 减少重复计数
- 减少 ID 断裂

---

# 6️⃣ No-Spawn Zone

新 Detection 出现前：

```python
_too_close_to_existing_track()
```

检查附近是否已有旧轨迹。

作用：

- 防止同一目标重复生成新 ID

---

# 7️⃣ 稳定轨迹筛选（Visible Tracks）

只保留：

```python
hits >= min_hits_to_show
and
missed <= 1
```

的轨迹。

作用：

- 去除短命轨迹
- 去除闪烁框

---

# 8️⃣ 重复轨迹过滤（Duplicate Filter）

使用：

```python
is_duplicate_track_candidate()
```

判断两个 Track 是否属于同一目标。

依据：

- IoU
- 中心点关系
- 尺寸相似度

作用：

- 防止重复计数

---

# 9️⃣ Confirmed 计数

满足：

```python
hits >= confirm_min_hits
```

后：

- 分配 display_id
- realtime_count +1

规则：

- 每个 Track 只计数一次

作用：

- 统计独立微生物个体数量

---

# 🔟 类别投票（Class Voting）

每个 Track 持续记录历史类别：

```python
class_votes
```

最终类别由多数投票决定：

```python
majority_class_from_votes()
```

作用：

- 提高分类稳定性

---

# 1️⃣1️⃣ Best Crop 更新

每帧：

- 按 bbox 裁剪 crop
- 计算 sharpness（Laplacian）
- 综合 conf / 面积 / 清晰度评分

如果更优：

```python
best_score()
```

则更新：

```python
best_crop
```

作用：

- 为每个微生物保留最清晰代表图

---

# 1️⃣2️⃣ Track Finalize

当：

```python
missed >= finalize_missed_thresh
```

认为该目标已离开画面。

执行：

- 保存 best crop
- 写入 confirmed CSV

---

# 1️⃣3️⃣ 输出结果（Output）

输出内容：

## CSV

- confirmed_microbes.csv

记录：

- display_id
- class
- best frame
- sharpness
- class votes

---

## Best Crop

每个 confirmed 微生物：

- 保存一张最佳截图

---

## Video

输出可视化视频：

- bbox
- class
- display_id
- realtime count
