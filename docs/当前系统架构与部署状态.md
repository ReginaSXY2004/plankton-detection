# 当前系统架构与部署状态 5.12

## 项目目标

构建一个用于水体微生物实时检测、跟踪与计数的边缘视觉系统，支持：

* 实时 detection
* individual tracking
* realtime counting
* best crop 保存
* 长时间连续运行
* 边缘设备部署（Jetson AGX Orin）

当前系统主要面向：

```text
实验室视频 → 实时视觉分析 → 边缘部署验证
```

---

# 当前系统架构

## 1. Detection

当前使用：

```text
YOLOv8n Multiclass Detection
```

支持类别：

* daxingzao
* jianshuizao
* lunchong
* xiangbizao
* xianchong
* weizhi

当前已完成：

* detection 后处理
* 去重（deduplicate）
* confidence filtering
* detection → tracking 数据转换

---

## 2. Tracking

当前使用：

```text
自定义 MicrobeTracker
```

支持：

* Hungarian matching
* reconnect
* no-spawn filtering
* duplicate suppression
* class voting
* confirm mechanism
* finalize mechanism

当前统计基于：

```text
confirmed track
```

而不是逐帧 detection。

---

## 3. Detector Backend

当前已初步解耦 detector backend 与主 pipeline。

结构：

```text
main.py
↓
YoloDetector
↓
Ultralytics YOLO backend
```

当前 `detector.py` 已支持：

* `.pt`
* `.engine`

后续可扩展：

* TensorRT
* ONNX
* OpenVINO

# 当前仍存在的风险

## 1. Writer 仍为同步写入

当前：

```text
writer.write(frame)
```

仍在主线程。

未来可能需要：

* async writer
* bounded queue
* writer watchdog

---

## 2. 长时间稳定性仍未完全验证

当前大部分测试仍属于：

```text
短视频 / 中等长度视频
```

未来需要：

```text
1~3 小时压力测试
```

验证：

* 内存增长
* writer 稳定性
* FPS 漂移
* GPU 占用
* 文件系统稳定性

---

## 3. Jetson 部署仍未实测

当前 TensorRT engine 基于：

```text
RTX 5070
```

Jetson AGX Orin 上：

* 需要重新导出 engine
* 需要验证 TensorRT compatibility
* 需要验证编码器性能
* 需要验证长时间运行稳定性

---
